How it works

01

Type it rough.

In a browser chat, VS Code, Word, email or Notepad. No extension, no plugin, no second window.

Ctrl+Alt+P rewrites the whole box. Add Shift to rewrite only what you selected.

Read the rewrite.

It opens in a review window next to your original. Edit it, answer its questions, or run it again.

Check every change.

Removed words in red, added words in green. You decide what happens next.

It keeps what you wrote.

Links, file paths, names, numbers and anything in quotes are compared after every rewrite. If one went missing, it gets put back, or you get a warning. Pasted code and logs are never touched.

Example
fix the crash in src/auth/login.cs, it started after v2.3.1, keep all 14 tests passing
Each highlighted detail must still be in the rewrite.

It asks instead of guessing.

If your draft leaves something out, PromptForge lists it as a question. It does not make up a length, an audience or a deadline. A prompt that was already good comes back unchanged.

Terminals are copy-only on purpose, because keystrokes there could run commands. Password fields are refused. Apps running as administrator can't be reached, so you get the result on your clipboard instead.

Talk instead of typing.

Tap Ctrl+Alt+D to start and again to stop, or hold it while you speak. The transcript is typed into the box, or rewritten first.

Uses Groq's Whisper model, so it needs the same free Groq key.

Set up in four steps.

  1. Get a free key at console.groq.com/keys. No card needed.
  2. Download PromptForge.exe and run it. Choose Yes to install. No admin rights, no .NET install.
  3. Paste the key in Settings, click Test connection, then Save.
  4. Click into any text box, type something rough, press Ctrl+Alt+P.

Questions

Where does my text go?

To the AI provider you chose (Groq by default), only after you press the hotkey. There is no PromptForge server. Your keys are encrypted with Windows DPAPI, and prompt text is never written to the log.

What does it cost?

The app is free. Groq's free tier allows 30 requests a minute and 1,000 a day, which is plenty for personal use. If you pick another provider, its own pricing applies.

What if it rewrites my prompt badly?

Press Esc and nothing changes. Your original is also kept in the tray menu under Copy last original text.

Can I add my own rules?

Yes. In Settings, Requirements, write standing requirements for each kind of task, or for all tasks. They are added word for word to the end of every rewrite and are never sent to the model.

Mac or Linux?

Not yet. PromptForge is a Windows 10 and 11 app.
