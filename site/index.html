PromptForge is a free Windows tray app that rewrites your rough prompt into a clearer one before you send it.

Select your draft in any text box, press Ctrl+Alt+P, and read the rewrite. Nothing is pasted until you press Replace.

Download PromptForge.exe Windows 10 and 11, MIT licence. Setup and the SmartScreen warning

How it works

  1. Write a draft

    Type it, or select it, in any normal text box: a browser chat, VS Code, Word, email, Notepad.

  2. Press the hotkey

    Ctrl+Alt+P rewrites the whole box. Add Shift to rewrite only the selection.

  3. Review the rewrite

    See it next to your original, edit it, or answer its questions and run it again.

  4. You decide

    Replace puts the rewrite in the box. Keep original leaves your text alone. PromptForge never presses Enter for you.

What it will not do

Submit anything for you
It changes your text only when you choose Replace. It never presses Enter.
Change your details
URLs, file paths, identifiers, numbers and quoted text are checked after every rewrite. Pasted code, stack traces and logs come back unchanged.
Make things up
When details are missing, the review window asks you. It does not fill the gap with a guess.
Type into a terminal
In Windows Terminal, cmd and PowerShell it copies the result and you paste it yourself. Password fields are refused.

Dictate instead of typing

Tap Ctrl+Alt+D to start and again to stop, or hold it while you talk and release. The transcript is typed into the box, or rewritten first if you choose.

Dictation uses Groq's speech model, so it needs a Groq key. The audio goes to Groq when you dictate, and to nobody before that.

It checks its own work

PromptForge ships with a test set of drafts. Settings, Data, Run quality check sends them through your model and grades the rewrites with code. Each case runs three times, so one lucky run does not hide a problem.

The checks look for dropped details, invented numbers, filler, and rewrites of prompts that were already good. A second model from a different provider can act as judge.

How to run it and compare two versions

Install in three steps

  1. Download PromptForge.exe from the latest release.
  2. Open it and choose Yes to install. It copies itself to your user folder and needs no admin rights.
  3. Paste an API key. Settings opens on the Model tab: paste the key, click Test connection, then Save. A free Groq key takes about a minute.

Then click into any text box and press Ctrl+Alt+P.

Windows will warn you

The exe is not code-signed, because signing needs a paid certificate. Windows SmartScreen may show "Windows protected your PC". Click More info, then Run anyway.

Check the download

Compare this hash with the one in SHA256SUMS.txt. A match shows the file is the one in the release. It does not show who built it.

Get-FileHash .\PromptForge.exe -Algorithm SHA256

Which AI provider it uses

PromptForge sends your text to the provider you choose, only after you press the hotkey. You bring the key.

ProviderHow you set it upGood to know
GroqPreset, the defaultHas a free tier. The only provider that does voice dictation.

OllamaPreset, runs on your PCNo key, and nothing leaves your machine. Small local models rewrite less well and use a lot of RAM.
